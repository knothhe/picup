为日常写作与分享而做

不依赖第三方图床，图片始终在你掌控的 S3 或 Cloudflare R2 中。

压缩与格式转换

上传前自动压缩并转换格式，显示节省比例，链接更快、存储更省。

并发上传与队列恢复

默认同时上传 3 张（可调 1–6），失败可单独重试；退出后队列自动保存并恢复。

全局快捷与菜单栏

⌘⇧U 选择上传，⌘⇧V 上传剪贴板；也可把图片直接拖到菜单栏图标上。

Cloudflare 一键授权

通过浏览器授权 Cloudflare，选择账号与 R2 桶即可，无需手动创建或粘贴密钥。

多配置与云端图库

多个存储配置随时切换，支持无密钥导入导出；分页浏览、搜索、重命名和删除云端图片。

安全与更新

手动密钥可保存到 macOS 钥匙串；应用更新使用 Ed25519 签名校验，确认后再重启。

三步开始

首次配置只需要一分钟。

连接存储

在「设置 → 存储」选择 Cloudflare 授权，或填写 S3 / R2 访问密钥。

测试权限

点击「测试上传与清理」，确认存储桶具有写入与删除权限。

上传并复制

拖入、选择或粘贴图片，一键复制 URL 或 Markdown。

也能在终端里用

CLI 与桌面端共用配置和凭据，适合脚本、编辑器插件与自动化流程。

  • 上传文件或直接上传剪贴板
  • 批量上传，输出 URL 或 Markdown
  • 可调并发与同名冲突策略
  • 在「设置 → CLI」中一键安装
# 上传文件
$ picup photo.jpg
# 上传剪贴板中的图片
$ picup
# 批量上传并输出 Markdown
$ picup a.png b.jpg --output markdown
$ picup a.png b.jpg --concurrency 2 \
    --collision rename --progress
