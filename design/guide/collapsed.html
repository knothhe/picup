指南设置

使用入门

完成配置，上传第一张图片。

打开存储设置
01

连接你的存储

在设置中选择 S3 或 R2，填写存储桶、访问凭据和图片公开地址。

R2 的 Region 使用 auto；AWS S3 使用桶所在区域，Endpoint 可留空。

02

检查连接

设置会自动保存。填写完成后点击「测试上传与清理」，测试会创建并删除临时对象，需要写入和删除权限。

03

上传与管理

拖入图片、选择文件或粘贴后上传。菜单栏还可直接选择图片或上传剪贴板。

成功后复制链接，在图库浏览、搜索和管理云端图片。图库缓存列表与缩略图，启动后先显示缓存再刷新。

路径变量

默认按内容哈希命名。可使用日期和扩展名变量自定义目录。

{year}/{month}-{day}-{md5}.{extName}
命令行

在「设置 → CLI」安装命令行工具，与桌面端共用配置。

picup photo.png
picup --output markdown
picup config
连接提示

Endpoint 不含 Bucket。Path-style 开启时 Bucket 位于请求路径，关闭时位于域名前。临时 AWS 凭据还需 Session token。

测试不验证公开读取，链接打不开时检查公开域名与桶读取权限。
