# 全局快捷上传、通知与大图库

[返回 README](../README.md) · [使用指南](usage.md)

「选择并上传」和「上传剪贴板图片」现在使用系统全局快捷键，默认分别为 `⌘⇧U` 和 `⌘⇧V`；在编辑器或其他应用中也能触发。其他命令仍按原有窗口和页面作用域工作。

在「设置 → 快捷键」录制、清除或恢复绑定。新键位被其他应用占用，或新设置保存失败时，原先成功注册的键位继续有效，新输入保留以便修改或重试。在「设置 → 通用 → 快捷上传与通知」查看当前实际生效的全局键位，并重试注册。Dev 与正式版同时运行时不能共享同一套系统热键；为其中一个版本改键，或退出占用键位的版本后重试。

应用退出时仅注销自己持有的快捷键。单纯关闭窗口或轻量模式回收界面会继续保留全局快捷上传入口。

## 后台上传通知

「设置 → 通用 → 后台上传完成通知」为所有 profile 共用，默认开启。仅在 Picup 主窗口和快捷上传面板均未获得焦点时，完成上传才显示系统通知；点击通知返回上传页查看结果。通知内容只包含完成、失败或取消摘要，不包含文件路径、存储凭据或图片链接。

启动应用不会请求通知权限。首次后台上传完成时，系统可询问是否允许通知。拒绝后，本次运行停止自动请求，上传结果仍保留；在系统设置中允许 Picup 通知，再到通用设置点击「重试通知」。关闭通知开关会清除尚未处理的通知请求和当前完成提示。

macOS 系统通知需要运行打包的 `.app`；直接执行 `picup-gui` 的开发进程仍使用应用内反馈。

## 大图库与目录加载

图库首先请求当前前缀下的一页云端对象，每次最多 200 个对象。对象中可能包含非图片文件，因此一次请求得到的图片可能少于 200 张，甚至为零；只要仍有后续页，就会显示「加载更多图片」。Picup 不会在后台自动枚举整个大桶。

在「当前目录」输入对象路径前缀，例如 `images/2026/`，点击「加载目录」即可直接向存储请求该范围，无需先扫描完整目录树。「全部目录」返回空前缀；原筛选器中的目录选项也会切换云端请求范围。切换目录会取消旧请求并清除旧选择；已经取消的结果不能覆盖新目录。

尚有后续页时，搜索、日期筛选和排序只作用于**已经加载的图片**。界面明确显示已加载数量与范围；逐步加载后结果会扩大。列表内的每页 20 张图片仍是本地浏览分页，与云端的「加载更多图片」分开。

完整桶列表与各前缀的分页快照分开缓存。部分目录或尚未加载完的列表不会覆盖已有完整桶缓存。刷新失败保留当前已加载内容；继续加载失败可重试当前页。云端删除和重命名仍保留原有确认与部分失败处理。
