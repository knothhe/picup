# 使用指南

[返回 README](../README.md) · [配置参考](configuration.md) · [CLI](cli.md)

## 连接存储

「设置 → 存储」的「连接方式」可在「Cloudflare 授权」和「访问密钥」之间切换。在 macOS 选择「Cloudflare 授权」后点击「连接 Cloudflare R2」，通过系统浏览器授权后选择账号、辖区和 R2 桶，再点击「连接所选存储桶」，即可自动保存为新的 profile，原有配置保留。相同 Endpoint 和 Bucket 会沿用当前公开地址，其他情况请手动填写；未配置公开访问的桶仍需先设置公开域名。发行者尚未配置 OAuth client 的构建会提示授权不可用，详见 [R2 OAuth 说明](cloudflare-oauth.md)。

选择「访问密钥」时选择 R2 或 S3，填写 Endpoint、Bucket、访问凭据和公开访问地址。Endpoint 不包含 Bucket；AWS S3 可留空，但需填写桶所在的 Region；R2 的 Region 使用 `auto`。

设置自动保存，保存状态显示在标题栏右侧，失败时可直接重试。填写完成后点击「测试上传与清理」：测试需要写入与删除权限；默认的同路径复用策略，以及可选的改名、跳过策略，还需要 `HEAD` 读取对象元数据的权限。测试通过不代表读取权限已验证，图片的公开读取需由存储桶或 CDN 单独配置。保存失败时保留输入，可修正后重试。

macOS 手动连接可点击「保存到 macOS 钥匙串」。成功写入并验证钥匙串、保存配置后，才移除配置文件中的明文密钥；失败时保留原配置与输入，不会自动迁移已有连接。桌面端与 CLI 共用钥匙串凭据。更换 Endpoint 或 Bucket 后，需在「替换凭据…」中重新保存对应密钥。

存储页只编辑当前 profile。上传图片前，可在侧栏顶部确认当前配置。已用 Cloudflare 授权的 profile 改用访问密钥前，需先断开授权；桶内图片会保留。

## 上传与菜单栏快捷上传

主窗口支持拖入、选择或粘贴图片，单张或批量上传。默认同时处理和上传 3 张，可在「设置 → 图片与输出 → 上传任务」调整为 1–6 张。界面显示已处理张数与单项传输字节；失败项可单独重试，取消后保留已完成链接与未完成任务。单项可复制 URL / Markdown，复制全部结果使用当前输出偏好。

上传页顶部的「处理选项」默认收起，点击摘要行展开后可调整压缩开关、输出格式、质量和最大宽度，按当前 profile 自动记忆，并与 CLI 共用。参数用于下一次上传；正在上传的批次使用开始时的参数。底部保留链接输出偏好和上传操作；「设置 → 图片与输出」保留上传任务、链接与剪贴板选项，压缩参数在页面内调整。

同路径图片默认复用已有链接，也可选择覆盖、自动改名或跳过。复用按对象路径判断；自定义模板生成相同路径时，不会进一步核对图片内容。复用显示「已复用」，不显示本次压缩节省比例；跳过显示「已跳过」，不计为上传失败，也不会进入下一次整批上传，仍可单项重试。

点击菜单栏图标默认打开快捷上传浮窗，可在「设置 → 通用 → 窗口与启动」改为打开主窗口。浮窗支持拖入图片、选择文件和上传剪贴板图片，添加后立即上传，并显示进度与结果。

macOS 还支持将一张或多张本地图片直接拖到菜单栏的 Picup 图标上：图标高亮时松开即可开始上传，并打开快捷面板显示进度。此操作沿用当前配置，与托盘点击行为无关；正在处理或上传时不接收新批次，未配置存储时会打开设置。文件夹、文本和网页链接不会触发上传。

- 快捷上传沿用当前 profile，只处理本次添加的图片，保留主窗口原有队列。
- 复制结果遵循当前输出与自动复制偏好。
- 再次点击菜单栏图标、按 Escape 或点击外部可收起浮窗，正在进行的上传会继续。
- 浮窗右上角可打开主窗口或设置；图库和配置管理在主窗口使用。未配置存储时，窗口入口直接打开存储设置。
- 进度和结果显示在主卡片中；失败时点击卡片可进入主窗口查看详情并重试，未配置存储时可直接点击卡片进入设置。
- 点击右上角「重置状态」可清除成功、失败或其他结果，恢复初始上传界面，保留主窗口队列、上传历史和剪贴板内容；处理或上传期间及初始状态下按钮禁用。
- 选择图片、上传剪贴板旁显示当前快捷键；更改绑定后同步更新，清空绑定后隐藏键位。

### 队列恢复

主窗口队列自动保存在配置目录下的 `upload-queue-v1`，最多 1000 项，包含待上传、失败、跳过及已完成结果。退出时取消进行中的上传，等待结果收尾并保存队列；再次打开仅恢复任务，不会自动上传，确认当前 profile 后可继续。

本地文件只记录绝对路径，不复制或修改原文件；删除或移动源文件后需重新添加。剪贴板源图以权限 `0600` 的独立文件保存，按内容去重复用，持久化源图合计上限为 256 MiB。超限或磁盘写入失败会提示保存失败，当前会话的任务仍保留，可移除部分任务后重试。

单个剪贴板源图丢失或损坏时，该项显示恢复失败，其他有效任务仍可恢复；损坏源图保留到明确移除该项，可重新添加图片。整个队列文件损坏或版本不受支持时保留原记录，暂停添加图片；确认不再需要后，可在上传页点击「重置上传队列记录」恢复添加与保存。队列恢复与图库缓存分别管理。

## 本地图片工具

侧栏的「图片工具」可独立批量压缩、转换格式和缩小图片，无需连接存储。拖入、选择或粘贴图片，按需展开默认收起的「处理选项」调整参数，选择导出目录后点击「处理并导出」。最大宽度为 0 表示不限，图片只缩小不放大；PNG 无损优化，动画保留原格式与帧。输出使用 `原文件名-processed.扩展名`，重名时追加编号，保留原图和已有文件。

页面显示每张图片的处理结果、实际大小与尺寸；失败项可重试，取消后保留已完成的导出文件。工具参数和导出目录在所有 profile 间共用，与上传参数分别记忆，不受 `PICUP_FORMAT` 等上传环境变量影响。工具列表仅保留在当前会话，退出后需重新添加源图。

## 多配置（profile）

「设置 → 配置」支持新建、复制、重命名和删除 profile。每个 profile 独立保存存储连接、凭据、路径模板、上传时的图片处理与输出偏好；语言、外观、快捷键、窗口及本地图片工具偏好共用。旧单配置会自动迁移为默认 profile。

点击侧栏顶部的配置卡片可在任意页面切换，菜单中的「管理配置…」进入配置管理页。配置入口只显示名称；收起侧栏后使用截断名称，悬停提示和菜单可查看完整名称与存储详情。

切换前保存当前编辑，保存失败时保留输入和当前 profile。上传或图库操作期间暂不可切换。切换后保留上传队列，待上传图片使用新 profile；图库会取消旧加载、清除旧选择，并恢复各 profile 的搜索和筛选。

删除 profile 不删除云端图片，且始终至少保留一个 profile。CLI 的临时 profile 选择见 [CLI 文档](cli.md)。

「配置迁移」支持导入、导出。导出只包含存储地址、路径、图片和输出偏好，不含访问密钥、Session token、钥匙串引用或 Cloudflare 授权。导入预览后新增配置并生成新 ID；重名自动加后缀，保留已有配置、当前选择和应用偏好。文件上限 1 MiB，每次最多 100 个配置；失败时保留预览和原配置。导入后需重新填写密钥或通过 Cloudflare 授权连接。CLI 的同类命令见 [CLI 文档](cli.md#配置迁移)。

## 图库

图库支持预览、搜索、筛选、排序、多选、下载、重命名与删除。每次向云端读取最多 200 个对象并展示其中的图片；点击「加载更多图片」继续读取，界面页码用于浏览已经加载的图片，不会自动遍历整个桶。可输入目录前缀并点击「加载目录」缩小云端查询范围，点击「全部目录」返回全部目录。列表尚未读取完时，搜索、排序和日期筛选只作用于已加载图片，当前结果不代表整个桶。

生效中的目录和日期筛选显示在工具栏上，可单独清除；选中图片后，底部浮出操作条，可批量复制链接或 Markdown、删除或全选当前页。搜索、目录、日期筛选、排序和页码会自动保存，重启后恢复；点击工具栏的重置按钮恢复默认视图。预览时右侧显示路径、大小、修改时间，以及链接与 Markdown 的复制入口。

删除会移除云端对象，已有链接将失效。桌面端统一在图库管理图片，已有本地上传记录仍可用 `picup history` 查询。

### 缓存

对象列表和缩略图保存在系统缓存目录下：正式版为 `picup/gallery-v1`，Dev 为 `picup-dev/gallery-v1`。缓存跨重启复用，并按存储连接和目录前缀隔离。打开图库先显示缓存，再刷新云端首批对象；刷新或加载更多失败时保留已有内容，可重试。缩略图随对象版本变化失效。可用绝对路径 `PICUP_CACHE_DIR` 指定缓存根目录，实际图库缓存写入其下的 `gallery-v1`；详见[配置参考](configuration.md#缓存与本地队列)。

缓存默认最多 256 MiB，按最近使用情况自动淘汰。「设置 → 通用 → 清理图库缓存」可手动清理，下次打开图库时重新加载。原图预览和下载直接读取云端，清理缓存不会删除云端图片。

## 导航与快捷键

侧栏底部提供指南和设置，关于位于「设置 → 关于」；收起侧栏后，侧栏缩为图标栏，导航入口保持原位。进入设置后，侧栏换为设置目录，按「当前配置」「应用」「其他」分组，顶部「返回」回到原页面。关于页可查看版本与配置路径；构建信息和主要依赖默认收起，可分别点击展开。

| 操作 | 默认快捷键 |
| --- | --- |
| 选择图片（主窗口） | `⌘O` |
| 粘贴图片（上传页 / 图片工具） | `⌘V` |
| 上传队列 | `⌘↩` |
| 选择并快捷上传（全局） | `⌘⇧U` |
| 快捷上传剪贴板图片（全局） | `⌘⇧V` |
| 切换侧栏 | `⌘B` |
| 打开设置 | `⌘,` |
| 退出应用 | `⌘Q` |

「设置 → 快捷键」支持录制、更改、清除、单项恢复和恢复全部默认，冲突会直接提示。选择并快捷上传、快捷上传剪贴板图片是系统全局快捷键，Picup 在后台、主窗口关闭或轻量模式下也可使用。其他快捷键在对应应用窗口或页面生效。注册失败保留原有效绑定，可关闭冲突应用或修改绑定后重试；清空绑定会取消全局注册。界面图标提示当前绑定。

全局操作提示位于窗口左下角，成功提示短时显示，主窗口失去焦点后仍继续计时；失败提示可手动关闭。

「设置 → 通用 → 快捷上传与通知」的「后台上传完成通知」默认开启，仅在 Picup 位于后台且有上传结果时发送。首次实际发送时由系统请求通知权限，不会在启动或切换偏好时请求；macOS 需使用打包的 `.app`。点击通知返回上传结果。拒绝后停止自动请求，可在系统设置允许通知后点击「重试通知」；通知失败不影响已保存的上传结果。

## 窗口与启动

侧边栏的收起或展开状态会自动记忆，退出并重新打开应用后恢复，所有 profile 共用。

「设置 → 通用 → 窗口与启动」统一管理以下偏好，在所有 profile 间共用并自动保存：

| 选项 | 行为 |
| --- | --- |
| 关闭窗口后继续运行 | 默认开启，关闭后可从菜单栏重新打开；完全退出使用「退出 Picup」或 `⌘Q` |
| macOS Dock 图标 | 展示、隐藏或跟随主窗口 |
| 托盘点击行为 | 默认打开快捷上传浮窗，可改为打开主窗口 |
| 轻量模式 | 默认关闭，空闲时释放窗口与图库内存 |
| 开机自启 | 默认关闭，通过系统登录项在登录后后台启动；macOS 需使用打包的 `.app` |

开启轻量模式后，主窗口与快捷面板均关闭满一分钟，且无上传、图库写操作或未完成编辑时，会销毁窗口并释放列表、预览与缩略图内存，保留托盘、待上传图片和上传结果。重新打开时重建界面并按需加载图库；计时期间打开任意窗口会重新计时。
